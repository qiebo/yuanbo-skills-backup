# 正式方案去 AI 味（Formal Dereification）

## 1. 核心原则：去"空、套、虚、机械"，不丢"庄重、有据、有节奏"

本文件是「远播方案助手 V2.0」的**阶段 6.5 专业表达检验**规则源。它复用通用去 AI 味能力的**检测目录**（最毒句式、客套开场/结尾、模板过渡、模糊限定、官腔空话、无证据强词），但**刻意不使用其口语化注入配方**。

原因：本 skill 产出的是政府申报书、学校建设方案、采购技术方案、领导汇报稿等**正式文档**。通用去 AI 味的"注入活人感"手段——口语锚点（`说实话`/`怎么说呢`）、语气词（`啊呢吧嘛`）、句子碎片、用"我"的体验、戛然而止式结尾、删除冒号/破折号/双引号——会把这些正式文档改写成微信闲聊体，**反而更不专业**。

所以本文件的改写目标是：

- **去掉** AI 腔的"空（无对象无尺度）、套（模板三段式）、虚（模糊限定与官腔）、机械（连接词与句式雷同）"；
- **保留** 庄重文风、完整句、必要标点、证据化措辞（`拟`/`建议`/`预计`）、长短句变化带来的节奏。

> 一句话：**让方案读起来像一位有见识、有分寸的业内人在认真陈述，而不是 AI 在输出信息，也不是销售在聊微信。**

## 2. 检测目录（由 `validate_project.py::check_formal_ai_tells` 自动扫描）

全部以 **warning 级** 呈现，作为质量门禁提示，**不阻断交付**（语言润色非一票否决项）。warning 项应在交付前尽量减少。

### 2.1 最毒句式（出现即修，最高优先级）

| 模式 | 修法 |
|---|---|
| `不是A，而是B` | 直接写 B，删掉对比框架 |
| `心中涌起…` / `眼中闪过…` / `声音不大，却…` | 用具体身体反应或行为替代情绪告知 |
| `仿佛/犹如/宛若…一般` | 删或白描 |
| `他/她知道…` / `他/她终于明白了…` | 用行为展示认知，不告知 |

### 2.2 客套开场（第一句必须就是内容）

删：`很高兴为您解答`、`当然可以`、`好的，我来为您分析`、`这是一个非常好的问题`、`感谢您的提问`、`非常感谢`。

### 2.3 客套结尾 / 总结升华（在最后一个有实质内容的句子结束，戛然而止）

删：`综上所述`、`总的来看`、`总而言之`、`希望以上信息对您有帮助`、`如有任何疑问请随时联系`、`希望对您有所启发`、`通过以上分析可以看出`、`这一刻，他终于明白了…`。

### 2.4 模板过渡词（直接接内容，不另起套话）

删：`值得注意的是`、`需要指出的是`、`值得一提的是`、`不可忽视的是`。

### 2.5 模糊限定（删，或给出具体边界）

删：`在某种程度上`、`从某种意义上（来说）`、`一般来说`、`通常情况下`、`可以认为`、`可以说`、`总体而言`。

### 2.6 官腔空话（补出真正的主语、动作与结果）

| 原写法 | 改写方向 |
|---|---|
| `在相关部门的共同努力下` | 谁做的、什么结果 |
| `为…奠定了坚实基础` | 具体成果（如"把 BUG 率从 8% 降到 3%"） |
| `持续赋能业务发展` | 具体动作与时间 |
| `强化…能力建设` | 建设了什么、达到什么标准 |
| `打造…新格局` | 说清服务对象与可复制成果 |

### 2.7 无证据强词（必须降级或补证据）

`打造区域标杆`、`全面领先`、`行业领先`、`国内一流`、`世界一流`、`对标一流` → 无法证明时自动降级为 `拟形成`/`重点建设`/`对标`/`探索`，并在事实证据台账登记。

> 注：本 skill 已有的 `HIGH_RISK_WORDS`（`全国首个`/`唯一`/`率先`/`领先`/`填补空白`/`示范标杆`）仍按原规则作 error 级阻断；本节为其补充正式文风下更隐蔽的强词表述。

### 2.8 空泛修饰词（补对象与可量化尺度，或删除）

`高质量`、`显著提升`、`显著增强`、`扎实`、`有力`、`全方位`、`多层次`、`系统性` —— 单独出现且无对象/尺度时视为空泛。例："全面提升学生综合素养" → "本学年新增 3 门项目式课程，覆盖 4 个班级约 160 名学生，期末项目完成率 92%"。

### 2.9 机械化连接词（累计 >3 次预警）

`此外` / `然而` / `因此` / `与此同时` / `另一方面` 累计出现超过 3 次，提示句式雷同、模板感重，建议精简或替换为 `还有`/`不过`/不用。

## 3. 改写策略（保留正式感的前提下注入"人味"）

通用去 AI 味的"注入灵魂"配方中，**只有以下两条适配正式文档**，其余禁用：

- ✅ **节奏变化**：长短句交替，关键判断用稍短的句子独立成段，避免每段两句话、结构一模一样。
- ✅ **有分寸的判断**：在证据允许范围内给出明确立场（"这一设计，我们认为优先级最高的是…"），而非永远中立报道；但用 `我们认为`/`本项目判断` 代替口语化的 `说实话`/`我琢磨了很久`。

**明确禁用的通用配方（正式文档不适用）**：口语锚点（`说实话`/`怎么说呢`/`你想想看`）、语气词（`啊呢吧嘛`）、句子碎片、用"我"的体验替代客观判断、戛然而止式结尾、删除冒号/破折号/双引号。

## 4. 自检清单（交付前通读一遍）

- [ ] 是否存在 `不是A，而是B`、情绪告知式空壳、比喻陈词？
- [ ] 是否有客套开场或总结升华套话？
- [ ] 是否有 `值得注意的是` 等模板过渡词？
- [ ] 是否有 `在某种程度上`/`可以说` 等模糊限定？
- [ ] 是否有 `在相关部门的共同努力下`/`为…奠定基础` 等官腔空话？
- [ ] 是否有 `区域标杆`/`领先`/`一流` 等无证据强词？
- [ ] 是否有 `高质量`/`显著提升` 等空泛修饰且无对象尺度？
- [ ] 机械化连接词是否超过 3 次？
- [ ] 每段是否承担明确功能（事实/问题/判断/方案/验收），而非对仗工整的空话？
- [ ] 通读节奏：是呼吸顺畅，还是长句与模板句堆叠到喘不过气？
