# ERP §6 API token 占位文件（请勿提交真实 token）
#
# 用法（三选一，优先级从高到低）：
#   1. 运行时传参：  python scripts/fetch_erp_catalog.py --token-file <本文件或含 token 的文件>
#   2. 环境变量：    set ERP_API_TOKEN=你的token   （linux/mac: export ERP_API_TOKEN=...）
#   3. 把本文件重命名为 erp_apikey.txt 并填入真实 token，
#      脚本会自动在 assets/ 或脚本同级目录找到它。
#
# token 内容：纯文本一行即可，带不带 "Bearer " 前缀都会被正确剥离。
# 真实接口地址（可被 ERP_API_BASE 环境变量覆盖）：
#   https://erpapi.yishengya.cn/api
