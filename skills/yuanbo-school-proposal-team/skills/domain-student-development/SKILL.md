# Domain · 生涯 / 心理 / 学生发展

## 1. 核心设计链
优先使用：

`学生成长需求 → 服务场景 → 课程/活动/测评/指导 → 空间与平台 → 教师运行机制 → 持续支持`

不要从“要摆哪些产品”反推学生服务体系。

## 2. 三种视角
### 生涯主导
典型逻辑：认识自己 → 探索外部世界 → 形成方向 → 做出选择 → 付诸行动。

初中更重兴趣、自我认识、职业启蒙、学习方式；高中可进入选科、专业探索、升学路径、生涯决策和行动规划。

### 心理主导
典型结构：心理教育与预防 → 日常支持 → 团体/个体辅导 → 家校协同 → 必要时专业转介。

方案建设重点是专业边界、隐私、可达性、舒适度、常态运行，不做诊断或治疗效果承诺。

### 综合学生发展
把生涯、心理、学习支持、成长指导、学生活动和家校服务组织成一套学校学生支持系统，避免各功能“各有一间房但彼此无关系”。

## 3. 课程/服务设计
不要强制三级课程。可按真实运行场景组织：
- 面向全体学生的课程/活动；
- 年级关键节点主题支持；
- 测评与个体反馈；
- 团体辅导/工作坊；
- 个体咨询或生涯指导；
- 家长/教师支持；
- 学生自主探索资源。

每项说明：对象、触发场景、实施主体、活动过程、输出/记录、空间或平台依赖。

## 4. 空间关注
- 开放探索区与私密支持区的边界；
- 咨询、团辅、测评、课程、活动之间的声环境与动线；
- 预约/等候/进入/离开过程中的隐私；
- 温和、非标签化的空间体验；
- 可重组家具与多场景使用；
- 资料保管、数据隐私、转介与危机处置边界。

## 5. 表达分寸
“学生发展中心”的高级感不来自堆“AI、数字化、未来”，而来自清晰育人理念、学生视角、服务闭环、专业边界和可持续运行机制。
