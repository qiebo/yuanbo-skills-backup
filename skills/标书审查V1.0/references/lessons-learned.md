# 标书审查 — 经验教训库（lessons-learned）
> 每次审查后把用户 / 招投标人员的反馈沉淀为案例，持续改进审查准确度。
> 案例格式：误判描述 / 根因 / 修正规则 / 对应 skill 改动。

## 案例 1：技术偏离表「空白=完全响应」被误判为澄清风险（2026-08-18）
- **误判描述**：三份响应文件技术偏离表均为空白+笼统"完全响应"，子代理与终审将其列为"评审时存在被要求逐项澄清的裁量风险"。
- **招标文件原文**（格式四注）：注：1、若本表空白或只填写"无"或未列明有负偏离的，均视为完全响应采购文件所有技术要求，不提供此表作无效响应处理。
- **根因**：
  1. 基准虽提取了注1规则，但未标注为"明示允许/豁免"权威清单，权威性不足，子代理未将其视为约束；
  2. 子代理提示词未强制"明示允许不得列为风险"，子代理凭通用审查经验（行业常见提示"空白偏离表有澄清风险"）凌驾于招标文件明示条款；
  3. 终审无"风险项 vs 明示允许清单"交叉校验，误判一路贯通到最终报告。
- **修正规则**：招标文件明示允许的形式不得列为风险（铁律4）；风险必须有招标文件条款依据；形式合规 ≠ 实质响应，仍须核对正文参数是否真实达标。
- **对应 skill 改动**：新增铁律4；基准模板新增 §七·五 明示允许/豁免条款清单；子代理提示词新增 R1-R4 硬性规则；终审新增交叉校验步骤（audit_risks.py）；checklist 第3/7节补充明示允许判定规则。
