# Top Design · 顶层设计方法

顶层设计是建设方案的核心竞争力。目标是形成 **新颖、高级、有记忆点，同时能控制后文结构** 的设计，而不是单纯造词。

## 1. 先找项目内核
用四个输入交叉判断：
- 学校基因：培养目标、校训精神、校史文脉、已有优势；
- 真实任务：本次到底要解决什么建设问题；
- 学生成长/服务逻辑：学生在这里如何学习、获得支持或持续成长；
- 项目载体：课程/活动/服务、空间、设备/平台、运行机制。

优先寻找“已有基础 × 未来方向 × 本次建设任务”的交集，不把校训当万能来源。

## 2. 顶层设计五件套
每次至少形成：
1. **项目定位**：一句话说清要建成什么；
2. **核心概念/命名**：需要时形成 4-8 字左右有记忆点表达；
3. **总体结构**：内容如何组织；
4. **项目主线**：学生/服务/项目如何运行；
5. **差异化记忆点**：客户会因为什么记住它。

同时给出**详略主张**：明确指出本项目最值得浓墨展开的核心板块（供 Writer 定大纲时作为 detailed 章），以及只需简写带过的常规板块——方案要重点突出，而不是全篇均匀铺陈。

## 3. 三候选内部比较
内部形成 3 个方向，不必全部展示给用户。评分：
- 学校专属性 25；
- 对课程/空间/服务的解释力 25；
- 新颖与记忆点 20；
- 可展开/可落地 20；
- 表达质感 10。

选择能控制后文而不是最好听的方案。

## 4. 概念可用，但必须通过五个测试
- **专属性**：换学校是否仍完全成立？
- **解释力**：能否让复杂内容更易理解？
- **新颖度**：是否只是“智慧、未来、一体化”的组合？
- **映射性**：每个“核/翼/境/维/层”具体对应什么课程、空间或服务？
- **删除测试**：删掉后信息不减少且更自然，则不要展示概念。

“一核两翼、三层、三境、X+Y、动词链”都不是禁用词，只有空架构才是问题。

## 5. 领域差异
### 科创 / 科学教育
高级感可来自：
- 前沿技术与真实产业；
- 科学研究与工程循环；
- 数据—实验—制造—验证；
- 多实验室/课程协同；
- 学科基础与高阶研究衔接。

### 生涯 / 心理 / 学生发展
高级感更多来自：
- 对学生成长阶段的理解；
- 从普遍教育到个体支持的服务体系；
- 课程、测评、咨询、活动、家校协同的组织逻辑；
- 空间体验、隐私、开放性与持续运行；
- 学校育人理念的自然落地。

不要把学生发展项目强行科技化。

## 6. 内部逻辑 ≠ 客户文案
内部可以写：痛点、校训转译、销售抓手、竞争差异、方案取舍。
客户稿应改写为：背景判断、建设定位、设计逻辑、课程/服务结构、空间组织和运行机制。

### 反例
“2.4 校训转译：将‘格物致知’转译为三项建设行为……”

### 更自然
“课程以真实数据、实验验证和工程优化为主线，使学校强调的实证探究精神落实到学生具体的学习活动中。”

## 7. 商务分寸
对成熟名校，优先表达“承接、深化、协同、延展、形成载体”，避免“补课式”叙事。除非证据明确，不要写“学校缺乏、明显不足、亟待改变”。
