# 标书审查详细清单
> 审查时逐项对照，避免遗漏。判定结果记：✅ 已响应 / ❌ 缺失 / ⚠️ 部分 / ？无法判定（图片/原件）。
> 凡标注「？无法判定」的，均因证据以图片承载、文本不可见，须核对盖章正本与随附原件。
## 1. 废标 / 无效响应（最高优先级）
> 下列「依据：」为常见条文锚定，仅供增强权威性，**非法律意见**；条文以现行有效版本为准，重大情形请咨询法律顾问。
- [ ] 保证金：若要求，是否已提交
     依据：87号令（财政部令第87号）第33条（投标保证金）、第63条（未按要求提交可作无效）
- [ ] 递交：是否逾期 / 未送达 / 未密封 / 电子文档不合规
     依据：87号令 第33条、第41条（投标文件递交与密封）；《政府采购法》第36条（废标情形）
- [ ] 信用：是否列入失信、税收违法、严重违法失信名单
     依据：《政府采购法》第22条、《政府采购法实施条例》第19条；《政府采购法》第77条（虚假材料/失信处理）
- [ ] 资格：资格条件是否符合国家规定与文件
     依据：《政府采购法》第22条
- [ ] 关联：是否与其他供应商存在控股/管理关系或高管交叉
     依据：《政府采购法实施条例》第18条
- [ ] 报价：是否 > 最高限价
     依据：87号令 第60条（报价超预算/限价处理）；《政府采购法》第36条
- [ ] 有效期：响应有效期是否 < 要求天数
     依据：87号令 第23条（投标有效期）
- [ ] 签章：是否按格式签字盖章、是否齐全
     依据：87号令 第63条（投标文件签署盖章要求）
- [ ] 其他法定无效情形
     依据：《政府采购法》第36条
- [ ] 格式四注：是否提供报价明细表、明细合计是否 = 一览表
     依据：87号令 第60条
### 1.x 电子标（CA / 加密 / 平台）专用核查
- [ ] CA 数字证书：是否使用有效 CA 证书签章、证书是否在有效期内
- [ ] 文件加密 / 解密：加密投标文件是否能正常解密、解密后内容完整
- [ ] 平台上传：是否取得交易平台「上传成功」回执、回执编号与文件对应
- [ ] 电子签章完整性：电子签章是否完整、未被篡改、与签章主体一致
- [ ] 递交（电子标语境）：是否在截止时间前完成平台提交、是否因格式/大小/类型被平台拒收
- [ ] 签章（电子标语境）：电子签章是否符合交易平台规范、是否每页/关键页签署
     依据：参照《电子招标投标办法》（发改委等八部委20号令）相关条款
## 2. 资格性
- [ ] 营业执照：有效、经营范围匹配
- [ ] 财务：健全财务会计制度；净资产是否为负、成立时间是否过短（资不抵债风险）
- [ ] 税收 / 社保：依法缴纳纪录
- [ ] 信用截图：信用中国、中国政府采购网无失信（？图片）
- [ ] 特定资质：行业许可、软著、厂家授权（如要求，？图片）
- [ ] 业绩：类似项目数量/金额门槛（合同/中选通知书，？图片）
## 3. 符合性 / 形式
- [ ] 签字盖章齐全（法人、代理人、各附表）
- [ ] 格式 / 装订 / 份数（正副本、电子版光盘/U盘）
- [ ] 响应文件组成完整
- [ ] 偏离表已提交（空白/只填"无"=完全响应等**明示允许形式判合规**，见基准 §七·五；不得列为风险，铁律4）
- [ ] 形式合规 ≠ 实质响应：偏离表空白仅解决形式，仍须核对正文参数是否真实达标（铁律3/4）
## 4. 重点（★/▲）条款实质性响应
- [ ] 每项 ★/▲ 条款均有响应
- [ ] 响应满足或优于最低要求
- [ ] 每项均附支撑证据（截图/清单/大纲）
- [ ] 不同章节之间无矛盾
## 5. 价格与一致性
- [ ] 总报价 ≤ 最高限价
- [ ] 单价在分项限额内
- [ ] 税率计算正确
- [ ] 大小写金额一致
- [ ] 无异常低价（恶意低价/围标风险）
- [ ] 付款条件符合
## 6. 技术参数
- [ ] 全部技术参数已响应
- [ ] 声称有检测报告/证书支撑
- [ ] 产品型号全文一致
- [ ] 引用标准现行有效
- [ ] 交付周期合理
## 7. 偏离表诚信（红线）
- [ ] 偏离表声明与正文参数一致
- [ ] 凡「无偏离」项，正文确无超出/不足
- [ ] 存在「无偏离」但参数不符 → 单列 🟠 诚信风险
- [ ] 偏离表空白=完全响应属**形式合规**（基准 §七·五），但正文参数低于招标要求仍属实质负偏离/诚信风险（铁律3/4）
## 8. 文档完整性
- [ ] 投标/供应商名称全文一致
- [ ] 需签字盖章处均已签署
- [ ] 日期逻辑合理（无未来日期、无早于开标日期）
- [ ] 页码连续
- [ ] 无残留占位符（[X]、[TBD]、[采购人名称] 等）
- [ ] 图片证据（证书/合同/截图/签章）已随附原件或清晰图片
## 9. 常见红旗（fraud indicators）
- [ ] 检测数据与客户值完全相同（造假迹象）
- [ ] 合同缺签名或留白
- [ ] 过期证书当作有效提交
- [ ] 第三方材料无明确授权
- [ ] 不同文件公司名不一致
- [ ] 盗用网络图片（可见水印）
- [ ] 大量复制粘贴的填充内容
## 10. 内容一致性 / 前后矛盾（字段串行 · 跨位置冲突）
> 机检脚本 `scripts/crossref_check.py`（→ `output/机检_内容一致性.md`）机械列出疑似项；**命中仅作提示不自动判违规**（品牌可为独立商标、产地可异地代工），须人工对照原文复核判定去向。子代理断言任何此类结论前必须先读机检结果（铁律/R5），不许心算或凭印象。
- [ ] 分项报价/采购清单表内字段是否串行（品牌/产地/型号错位链）：品牌=另一行制造商字号、型号前缀对应其他制造商、产地与制造商地名冲突
- [ ] 表内录入错列 vs 真实贴牌/套牌：错位链 + 质保单/授权 → 判断是"改表可解决"还是"触及实质响应/诚信"
- [ ] 同一型号被多个不同产品或多行重复使用，疑规格型号错列
- [ ] 跨位置敏感字段是否一致：项目编号（含不同写法）、投标主体公司名、法定代表人姓名
- [ ] 金额大小写是否对应（机检对不上时人工核对）
- [ ] 报价/参数声明与正文是否一致（偏离表空白=形式合规，正文是否真实达标，铁律3/4）
- [ ] 是否混入多投标人/他版本文件内容（编号/盖章/公司名出多套 → 潜在串文件，可触及废标）
