## 二、废标（无效响应）条款清单
1. 未提交保证金（若要求）
2. 逾期 / 未送达 / 未密封 / 电子文档不合规
3. 列入失信 / 税收违法 / 严重违法失信名单
4. 资格条件不符合国家规定或磋商文件
5. 与其他供应商存在控股 / 管理关系或高管交叉
6. 报价 > 最高限价（**600000 元，补遗2号为准**）
7. 响应有效期 < 90 天
8. 未按格式签字盖章 / 不齐全（**含 CA 数字证书电子签章，补遗2号新增**）
9. 其他法定无效情形
- 格式四注：未提供报价明细表 / 明细表合计 ≠ 一览表

## 三、资格性条件
- 营业执照：有效、经营范围匹配
- 财务制度：健全财务会计制度
- 税收 / 社保：依法缴纳纪录
- 信用：信用中国、中国政府采购网无失信记录截图
- 特定资质：软件企业认定、厂家授权（如要求）
- 业绩：类似项目 ≥ 1 个（**补遗1号由 2 调减为 1**）

## 四、符合性 / 形式要求

- 响应文件组成完整
- 偏离表已提交
